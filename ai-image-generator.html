为日常创作准备的六件事

          
不追求繁杂，只把生图工作流里最常用的环节打磨顺手。

        

        

          
01
文生图与图生图
兼容 OpenAI images 接口；上传多张参考图自动走 multipart 图生图，序号即传参顺序，可自由调整先后。

          
02
Skill 提示词模板
导入 SKILL.md 一键套用提示词模板，自动识别 BOM、GBK 等多种编码；仅在当前会话保留，刷新即清空。

          
03
官方尺寸与质量档
内置 GPTEAM 文档 12 种画幅的目标尺寸，自动联动 aspect_ratio；质量档位 low / medium / high 可选。

          
04
并发任务队列
一次提交多张，按并发数自动调度；支持排队取消、失败重试、批量清理，生成状态一目了然。

          
05
额度与能力查询
一键查询 API Key 剩余额度、订阅与额度包余量；可读取当前分组可用的图片模型能力。

          
06
隐私与本地化
配置仅保存在本机浏览器 localStorage；接口不允许跨域时，可配合本地代理脚本直连中转。

使用说明

        
七步上手，从注册账号到批量出图。

      

      

        
1

        

          
注册并获取 API Key

          
前往 GPTEAM 平台注册账号，在后台创建并复制你的 API Key（sk- 开头），后续在「接口配置」中填入。

        

      

      

        
2

        

          
配置接口

          
打开控制台，点击右上角「接口配置」，填写 Base URL（默认已填 GPTEAM 地址）与你的 API Key，选择模型与并发数。配置自动保存在本机浏览器，不会上传。

          
页面与代理由本地服务提供（npm start 后访问 http://127.0.0.1:8787），同源请求不会触发跨域；若「本地代理」留空导致直连被拦截，填入 http://127.0.0.1:8787 即可。

        

      

      

        
3

        

          
验证连通与额度

          
在设置面板中点击「测试连接」确认接口可用；点击「查询额度」查看 Key 的剩余额度、订阅余量与额度包；「读取图片能力」可查看当前分组可用的图片模型。

        

      

      

        
4

        

          
填写提示词

          
在提示词框中描述想要的画面。也可以点击「导入 SKILL.md」导入提示词模板——支持 .md / .markdown / .txt，自动处理 BOM 与 GBK 编码，导入后点击标签即可套用；模板仅在当前会话保留，刷新页面自动清空。

          
快捷键：在提示词框中按 Ctrl + Enter 直接提交。

        

      

      

        
5

        

          
添加参考图（可选）

          
点击「＋」上传一张或多张参考图，图片缩略图上的序号就是传参顺序，可用 ‹ › 调整先后、× 删除。带参考图时自动走 multipart 图生图接口（/images/edits）。

        

      

      

        
6

        

          
选择尺寸、质量与张数

          
尺寸下拉框内置 GPTEAM 官方尺寸表（1:1 到 1:3 共 12 种画幅），选择后自动联动 aspect_ratio 写入额外参数；也可选「自定义尺寸」手动填写宽高。质量档可选 low / medium / high，默认不传跟随上游。张数决定一次提交几个任务。

        

      

      

        
7

        

          
生成与管理

          
点击「生成图片」后任务立即排队，按并发数自动调度；生成中可随时取消，失败可重试。完成后点击缩略图放大预览，支持下载单张。「详情」可查看该次请求的参数摘要，便于排查问题。

        

      

      

        
常见问题

        

          为什么生成失败提示"网络错误或跨域"？
          
直接用 file:// 打开页面时，浏览器会按跨域策略拦截接口请求。改用 npm start 启动本地服务，再访问 http://127.0.0.1:8787，页面与代理同源，请求即可正常发出。

        

        

          我的 API Key 会被上传吗？
          
不会。所有配置只保存在本机浏览器的 localStorage 中，请求由你的浏览器直接发往接口地址（或你指定的本地代理）。

        

        

          Skill 模板去哪里了？
          
模板仅保存在当前会话内存中，刷新或关闭页面即清空，这是有意设计，避免模板长期滞留。需要时重新导入即可。

        

        

          实际扣费以什么为准？
          
以 GPTEAM Portal 的请求日志为准。图片计费看张数、尺寸档与 upscale；详情见官方计费文档。

技术栈

        
页面为纯前端实现（HTML + 原生 JavaScript + CSS），不依赖任何框架与前端构建工具；数据全部保存在浏览器 localStorage。随附的 Node 本地服务（main.js）负责托管页面并转发接口请求，规避浏览器跨域限制。
